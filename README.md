One letter for your day: **G** — for "glitch". The day glitched: meetings rescheduled themselves, the build broke for no reason, the demo failed live. Vivid, funny, and true — and G is not the obvious pick.

## Run it

```sh
node main.ts
```

The program writes the single letter to `/output/entry.txt` (1 character, no trailing newline).
